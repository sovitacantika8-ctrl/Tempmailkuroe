# Akaishi Kuroe Temp Mail

Static HTML/CSS/JS Temp Mail yang memakai API:

- https://apiii-xrina.vercel.app/tools/tempmail
- https://apiii-xrina.vercel.app/tools/cekmail?token=TOKEN

Tidak membutuhkan API key.

## Deploy Vercel
1. Extract ZIP.
2. Upload `index.html`, `style.css`, dan `script.js` ke GitHub.
3. Import repository di Vercel.
4. Application Preset: `Other`.
5. Root Directory: `./`.
6. Build Command kosong.
7. Deploy.

## Fitur
- Generate email
- Token otomatis disimpan di localStorage
- Copy email
- Cek inbox
- Auto-refresh 10 detik
- Search inbox
- Tampilan mobile
- Tema Akaishi Kuroe

Catatan: API mengaktifkan inbox sementara sekitar 1 jam menurut respons endpoint.
